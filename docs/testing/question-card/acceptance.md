本次 E2E 发现并修正：编辑图标垂直对齐、窄输入长文本裁切、RN Web 未消费 accessibilityState 导致单选项无 aria-checked。发送按钮同时补 aria-busy。

后续按用户反馈修正：卡片宽度不超过480px或原生移动端时，输入框独占上一行，跳过/发送独占下一行右对齐。输入焦点使用主题色圆角边框，不使用浏览器黄色 outline；390px与320px均断言按钮行位于输入框下方至少10px，输入区域占满卡片内宽。相关普通E2E与录像复跑通过。

普通运行与录像模式的同一 Case 均通过。视频为八个已验证状态组成的 16 秒逐状态演示，不是连续操作录屏；0–2 秒初始、2–4 秒选择、4–6 秒发送成功、6–8 秒失败保留、8–10 秒重试、10–12 秒关闭、12–14 秒390px、14–16 秒320px。

验证：受影响的20项单测通过，最终源码 typecheck 通过。截图仅包含合成资料，未连接生产账号或向真实会话发送消息。真实完整会话链路、原生移动端键盘/读屏器和 OTA 安装后行为不在本次验收结论内。

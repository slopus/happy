# Kiro CLI models

Source: https://kiro.dev/docs/cli/models/
Fetched/verified: 2026-07-05

Kiro CLI supports model selection through the chat UI, the `/model` command,
and command-line defaults such as:

```bash
kiro-cli settings chat.defaultModel claude-opus-4.8
```

Happy passes the selected model to Kiro ACP as:

```bash
kiro-cli acp --model <model-id>
```

## Notes

- Auto is the recommended default; Kiro routes each task to the optimal model.
- Model availability can vary by region and account tier.
- Kiro docs advise restarting the client if an available model does not appear in the model selector.
- Kiro reasoning effort levels are controlled separately with `/effort` or `kiro-cli acp --effort <level>`.

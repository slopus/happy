## 可操作的路径

- **相关会话**：聊天中的影片工程卡片和右侧「本会话产物」可打开工作台。标题栏不添加常驻视频按钮。
- **普通会话**：「登录问题排查」仅有关联文档。共享目录不会自动把影片加入会话。
- **项目入口**：左侧品牌项目 → 项目产物 → 按名称和类型查看。可编辑工程与导出MP4分别标注。
- **独立打开**：从项目打开工程只显示工作台，不创建会话或发送AI要求。需要协作时明确选择已有会话或新建会话。
- **当前修改对象**：输入区的引用条单独表达本次AI目标。清除目标不移除关联；移除关联不删除工程，也不影响其他会话。
- **共同使用**：「宣传片创作」与「配乐调整」引用同一个工程ID。对话草稿独立，工作台标注和播放位置按工程保存。
- **反馈回改**：保存一条时刻标注 → 选择协作会话 → 加入本地演示队列。消息冻结工程、版本、标注时刻；之后切换会话不改写已发送目标。

顶部场景和主题切换是独立评审工具。产品路径使用侧栏、消息卡片、右侧产物和输入区入口。

## 实测与数据边界

本地Ego实际操作覆盖：普通与相关会话切换、项目混合产物、类型/名称筛选及空结果、MP4与原工程入口、独立打开后选择已有/新会话、按需关联和移除、清除本次目标、两会话草稿恢复、播放/暂停、时间线Home/End、标注保护、保存关闭重开及冻结目标消息。明确焦点循环补充后，正反Tab保留在关联模态中，Escape返回入口。

视口覆盖1680×920、1440×900、1280×800、390×844和320×780；后两项为模拟视口，不是实体手机或MacBook Air验收。浅色、当前深色及Gingham深色已核对，Gingham工作台表面为rgb(26,35,48)。390px的保存、发送、播放和关闭有命中检查及真实点击，320px项目与编辑器无整页横向溢出。

全部工程、服务准备、画面、轨道、消息与队列是合成演示。保存仅进入当前浏览器专用localStorage；本稿只提供一条可编辑的代表标注，没有实现完整多标注/多版本引擎。普通正文发送和标注发送均不会调用真实AI，不会修改原影片或源文件。准备和提示使用有限动画完成事件；播放rAF只绘制本地示意，无业务网络请求或状态轮询。CSP禁止业务连接。

真实会话－产物关系库、后台服务自动启动、通用产物登记、真实MotionHarness及模型回改尚不由本稿实现；当前工程实现差距沿[关联设计](../motion-project-entry/ASSOCIATION.md)和[集成报告](../motion-workbench-integration.md)维护。

公网根入口及九个资源逐字节一致。公网主流程中，2.5s标注在播放位置6.5s发送后仍锁定2.5s；清除目标后消息保持不变。公开窄屏的项目→工程→选择配乐会话→返回，以及普通会话无影片关联复验通过。最后回到项目列表的已验证画面已上报。完整检查和限制见[VALIDATION.json](VALIDATION.json)。

# PC Tag 清单分组设计规格

## 目标

把 PC Web「清单」页中的 Tag 从胶囊筛选器改为 Paws 原生密度的纵向列表。点击 Tag 后打开详情弹窗，弹窗内的关联会话按所属清单分组；用户可以从 Tag 的更多操作菜单删除 Tag，删除只移除 Tag 本身及会话关联，不删除会话。

## 用户可观察 Case

| Case | 用户操作 | 通过标准 |
| --- | --- | --- |
| C1 | 打开「清单」并查看 Tag 区域 | 每个 Tag 独占一行，显示图标、名称、颜色、会话数和更多操作入口；不再显示为胶囊。 |
| C2 | 点击一个有关联会话的 Tag | 打开宽屏详情弹窗；原清单侧栏保持不变，选中 Tag 有明确状态。 |
| C3 | 查看或折叠 Tag 详情 | 会话按清单顺序分组；未加入清单的会话位于「未归类」组；每组显示数量并可折叠。 |
| C4 | 从更多菜单删除 Tag | 二次确认文案明确说明不会删除会话；确认后 Tag 和所有 `tagIds` 关联消失，会话及其清单归属保持不变。 |

## 交互约束

- 点击 Tag 主区域只打开详情，不导航到会话，也不把侧栏切换成筛选结果。
- 点击更多操作入口不触发 Tag 详情。
- 详情弹窗中的会话行复用现有 `CompactSessionRow`，点击后沿用既有会话导航行为。
- 删除成功后关闭该 Tag 的详情和操作菜单。
- 详情组默认展开，组标题可切换展开状态，并暴露正确的可访问性状态。

## 数据与视觉约束

- 分组只基于现有 `SidebarOrganization.lists`、`sessions[sessionId].listId` 与 `tagIds`，不新增持久化结构。
- 清单组按 `organization.lists` 顺序；无效或空的 `listId` 归入「未归类」。空组不显示。
- Tag 计数包含所有可见会话，包括已置顶会话；清单本身仍保持既有置顶去重逻辑。
- 所有颜色使用当前 Unistyles 语义 token；Tag 的标识色继续使用现有清单颜色映射。
- PC 弹窗最大宽度 720px，并受现有安全边距与最大高度约束。

## 非目标

- 不新增子标签、Tag 合并或置顶能力。
- 不改变移动端页面、同步协议、服务端模型或 Tauri 历史代码。
- 本轮不自动部署生产 Web；生产部署仍需 PR 合入 `main` 后由既有 CI/CD 执行。

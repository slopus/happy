# PC Tag 清单分组设计规格

## 目标

把 PC Web「清单」页中的 Tag 从胶囊筛选器改为 Paws 原生密度的纵向列表。点击 Tag 后打开详情弹窗，活跃关联会话按所属清单分组，已归档关联会话统一收纳到最底部的「已归档」组；用户可以在弹窗内独立隐藏已归档会话，也可以从更多操作菜单删除 Tag。删除只移除 Tag 本身及会话关联，不删除会话。

## 用户可观察 Case

| Case | 用户操作 | 通过标准 |
| --- | --- | --- |
| C1 | 打开「清单」并查看 Tag 区域 | 每个 Tag 独占一行，显示图标、名称、颜色、会话数和更多操作入口；不再显示为胶囊。 |
| C2 | 点击一个有关联会话的 Tag | 打开宽屏详情弹窗；原清单侧栏保持不变，选中 Tag 有明确状态。 |
| C3 | 查看或折叠 Tag 详情 | 会话按清单顺序分组；未加入清单的会话位于「未归类」组；每组显示数量并可折叠。 |
| C4 | 从更多菜单删除 Tag | 二次确认文案明确说明不会删除会话；确认后 Tag 和所有 `tagIds` 关联消失，会话及其清单归属保持不变。 |
| C5 | 打开包含已归档会话的 Tag | 已归档会话不再按原清单分散，统一显示在所有活跃分组之后的「已归档」组。 |
| C6 | 在 Tag 弹窗的更多菜单选择「隐藏已归档」 | 「已归档」组从当前弹窗消失；侧栏 Tag 数量和详情总会话数仍包含已归档关联。 |
| C7 | 关闭并重新打开任意 Tag 弹窗 | 上次选择的显示/隐藏状态继续生效；该设置仅作用于 Tag 详情，不改变主清单的归档显示设置。 |
| C8 | 在 Tag 弹窗更多菜单删除 Tag | 操作菜单先关闭，再显示删除确认；删除语义与 C4 相同。 |

## 交互约束

- 点击 Tag 主区域只打开详情，不导航到会话，也不把侧栏切换成筛选结果。
- 点击更多操作入口不触发 Tag 详情。
- 详情弹窗右上角更多菜单同时承载「隐藏/显示已归档」和「删除 Tag」；打开菜单后键盘焦点落在归档可见性操作上。
- 详情弹窗中的会话行复用现有 `CompactSessionRow`，点击后沿用既有会话导航行为。
- 删除成功后关闭该 Tag 的详情和操作菜单。
- 详情组默认展开，组标题可切换展开状态，并暴露正确的可访问性状态。

## 数据与视觉约束

- 分组只基于现有 `SidebarOrganization.lists`、`sessions[sessionId].listId`、`tagIds` 与会话归档状态，不改变同步数据结构。
- 清单组按 `organization.lists` 顺序；无效或空的 `listId` 归入「未归类」；所有已归档会话最终归入单一「已归档」组。空组不显示。
- Tag 计数和详情总会话数包含活跃、置顶及已归档关联；详情中的清单数不把「已归档」计为清单。
- Tag 计数直接来自完整关联表，不随历史分页加载跳变；若关联会话尚未全部载入，详情明确显示当前已加载数与关联总数，不误报为空。
- 会话被永久删除时同步移除它的清单与 Tag 关联，避免关联计数长期残留为“未加载”会话。
- `tagDetailsHideArchived` 是设备本地持久设置，默认 `false`（显示已归档），在所有 Tag 详情之间共享，但与主清单设置隔离。
- 所有颜色使用当前 Unistyles 语义 token；Tag 的标识色继续使用现有清单颜色映射。
- PC 弹窗最大宽度 720px，并受现有安全边距与最大高度约束。

## 非目标

- 不新增子标签、Tag 合并或置顶能力。
- 不改变移动端页面、同步协议、服务端模型或 Tauri 历史代码。
- 本轮不自动部署生产 Web；生产部署仍需 PR 合入 `main` 后由既有 CI/CD 执行。

# 项目列表移动端布局修复

基线：`26c17bfdc08fe5b94ad2cc8ccb3ebbe66fc1fb31`。

## 问题与修复

Android 项目封面按钮沿用桌面的 `flexGrow: 1`，真实 ScrollView 中每张卡片在说明文字下方多出大块空白。保留 Web 的伸展规则，原生卡片按内容定高。

顶栏返回、更多和关闭采用透明圆形图标按钮；项目与子项目封面动作采用主题表面圆形按钮，列表动作采用透明图标按钮。保留 44dp 触控区、主题按下/选中反馈和键盘焦点，移除相邻图标额外扩展的触控范围。

## 原生验收

在 Android API 36 模拟器、1080×2424 / 2.625 DPR 的完整 App 中，通过独立合成账号、隔离服务和真实项目解析/RPC 运行；未连接生产账号或发送模型任务。

| Case | 结果与证据 |
| --- | --- |
| PM1 项目卡片连续排列 | 同一 379.05dp 宽卡片，原生 onLayout 高度由 630.48dp 降至 305.14dp；下一张卡片 top 从约 650.48dp 降至 325.33dp。最终 UIAutomator 读回两张卡片高均为 305.14dp，间距 20.19dp。 |
| PM2 图标触控与菜单 | 返回、更多、收藏及卡片菜单命中区均为 44dp；卡片菜单打开/取消、顶部更多面板打开/关闭后仍显示原项目列表。 |
| PM3 层级导航 | 从项目卡片进入子项目卡片列表，返回后恢复项目列表；第二张项目卡片可见可点。 |

最初的简化 Yoga 探针没有复现；上述根因与修复结论来自真实 Android 页面修改前后的测量。

现有 Android 开发壳加载当前源码时，根布局的动态 import 反复触发开发重载。验收期间仅将该 bootstrap 临时改为静态 import，完成后恢复；此适配未进入提交。本次不证明正式 APK/OTA 的启动或安装。

## 封面按钮配色修订

根据“白色按钮与封面不搭”的反馈，将收藏、更多、子项目动作、编号和子项目入口统一为主题色调的深色半透明表面及浅色前景。顶栏仍使用透明图标按钮。`imageOverlay` 语义 token 在浅色与深色主题中均保持暗底，按下、悬停、选中和焦点状态不会被普通照片工作区的表面覆盖。

- 116 项 `themePacks` 与整个 `goalBoard` 目录回归通过；包含普通、按下、悬停、选中及焦点状态。
- 全部 20 套主题的图片表面在纯白和纯黑图片下，文字对比度至少 4.5，危险图标至少 3；Gingham 明暗两态的 token 来源分别断言。
- 使用真实 Android 的 ProjectGallery、GoalBoardButton、图片、图标、字体和主题切换，验证 Gingham 浅/深色及收藏/取消收藏；卡片间距仍约 20dp。本轮使用隔离组件入口，不连接后端；临时入口已恢复。
- 新配色录屏 `mobile-overlay-colors-verified.mp4` 为 H.264、1080×2424、11.79 秒，完整解码通过并已通过 Happy 私人媒体卡发送；手机播放尚未确认。前一段 16.58 秒录像只证明最初布局版本，不代表最新配色。
- 该临时入口导致 Expo 生成空路由声明；已停止 Metro，使用既有 `repair-router-types.mjs` 从 78 个真实 App 路由恢复声明，再运行完整类型检查。未修改产品路由以绕过错误。
- 独立复核发现的 GoalBoardPanel 测试主题 mock 缺少新 token 已补齐，全目录回归通过；未在产品代码中加入 token 缺失兜底。
- 本轮仍未采集前后截图、验证生产发布或 iOS。

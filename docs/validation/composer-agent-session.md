# Web 会话内切换 Coding Agent 并新建会话

## 行为

沿用新建会话的设备启用列表和 Agent 轮换顺序。在已有会话的模型浮层中用当前 Agent 品牌图标代替重置。切至其他 Agent 仅暂存目标模型、推理强度和权限，不改变源会话。主按钮由发送箭头可逆展开为「新建会话」，分别使用 Claude 橙、Codex 蓝紫、OpenCode 灰。切回当前 Agent 恢复发送/停止及源设置。

主按钮复用 `useSpawnSession` 的创建、载入、首条提交和已创建会话恢复链；在相同机器及工作目录开启全新会话，不复制旧历史。源文字和本页生命周期内的附件草稿保留。目标不支持的附件在创建前拦截；待新建时 Enter/Tab 不创建会话。原生端使用空实现，保持原有入口。

## 验收

用户明确授权测试通过后直接合并发布；本轮只在三个专用测试会话发送只读提示，没有在既有业务会话发送测试消息或修改工程文件。

| Case | 真实浏览器结果 |
| --- | --- |
| C1 新建 Codex | Mac mini 执行端新建，读取当前工程 package.json 的 name，返回 C1 标记及 happy-app，已完成 |
| C2 Codex → Claude Code | 橙色新建按钮、源 URL 保持；点击后新 ID，真实 Claude 返回 C2 标记及 happy-app，已完成 |
| C3 Claude Code → Codex | 蓝紫色新建按钮；点击后再获新 ID，真实 Codex 返回 C3 标记及 happy-app，已完成 |
| C4 切回当前 Agent | 轮换回 Codex 后 URL 保持，普通发送恢复，暂存文字原样保留，未创建额外会话 |

环境为本分支完整 Expo Web、独立 localhost origin、已有服务器与真实 Mac mini 执行端。测试目录为本功能 worktree。未将分支部署至正式 origin；三个真实会话创建与推理均由现有服务完成。

独立代码评审发现并修复目标权限隔离、附件兼容门禁、离线源/在线机器选择和附件草稿保留。真实浏览器另发现原模型浮层 Escape 冒泡会关闭会话；补足 capture 阶段 keydown/keyup 和长按重复事件的所有权，红绿回归及真实流程复验通过。

测试初期保留的 Home 页面包含隐藏的同名控件，且首次账号同步会恢复中文语言。验收改用 session-message-input、目标主按钮语义和可见表面，避免读取隐藏 Home 状态。未创建失败的 Claude/Codex 测试会话冒充通过。

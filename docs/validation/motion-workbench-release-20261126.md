## 本次行为

- 去掉常驻标题栏剪辑入口，改为会话关联卡片、输入区通用产物选择器和项目产物页。
- 显式关联进入加密会话元数据，最多20条。打开、关联、当前修改对象、发送分别表达，同目录不自动关联。
- 原生MotionHarness画布、时间线和标注在隔离iframe中运行；自动准备执行机服务，资源经会话加密RPC传输。
- 标注和导出明确选择协作会话；发送锁定原工程、快照和标注版本。跨协作会话完成事件也能触发新构建交接。
- 原生未确认输入阻止路由和项目会话切换；异步返回后校验账号/工作区/组件所有者。创建会话载入失败时重试同一ID。
- 原生运行包许可、NOTICE、第三方通知和修改说明保留在下载信息中，不将安装版编译文件宣称为首选对应源码。

## 明确边界

项目级访问仍需要选择已有在线执行会话作为传输和目录授权；本次没有新增机器级独立编辑接口。通用文档/MP4沿用已有文件工作区，不假称已实现统一多类型登记库。原生Studio适配器依赖执行机安装的受支持版本；旧worker不热更新，其他机器须有对应执行端能力。没有原生依赖/runtime变化，不新增APK；共享JS是否触发OTA由既有分类器和CI决定。实体Air/手机与满期运行分别报告。

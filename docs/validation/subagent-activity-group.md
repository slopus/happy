# 会话子代理分组与进度

2026-11-25。用户已认可 existing-ui-design 的 T3 Code 参考交互稿并要求更新；此记录描述正式组件实现，不把静态稿的结果当成 App 接入证据。

## 实现范围

- 在原 `ConversationActivityStrip` 中将本回合子代理收进一个稳定分组，位置取第一条子代理活动；Skills 保持自己的顺序与现有行为。加载旧历史、追加代理或更新状态不重置用户的折叠选择。
- 组头显示头像堆叠、数量、运行/失败摘要及可确定的总历时。列表使用名称/当前动作两行，右侧对齐状态与单项耗时，窄列将状态/耗时上下排列。
- 行继续使用原有子代理详情回调与稳定 transcriptActivity 锚点，原生/触控直接点击。详情仅追加明确记录过的模型与推理强度，没有新增独立导航或弹窗。
- 普通、hover/pressed、selected、focus、边框与提示均消费当前主题的语义角色；字体沿用 Typography，缺少明确 provider 时使用通用分支头像。
- Web 的 hover/focus 卡复用现有 body Portal，支持 Escape、外点、滚动和 resize 关闭；不会抢焦点。标题/模型各最多两行、命令六行、失败三行，卡片高度受视口限制，完整记录继续走详情。

## 数据与时间

模型/推理强度/provider 仅取明确的子代理调用参数，不从父会话默认值推断。当前动作来自子代理自己的工具记录，遇到嵌套 Agent/Task 不进入其命令树。

起点取真实 startedAt/createdAt，生命周期终态事件决定结束时刻，避免将 spawn 返回当成子代理完成。同 ID 后续调用保留已有明确显示数据。组历时为最早起点到最晚结束/当前时刻；只有全部边界已知才显示。

每组仅在有已知起点的运行项时复用一个本地 Date.now 显示时钟；终态清理该时钟。没有新增业务状态请求、轮询或执行端更改。

失败摘要与最后动作分别派生：按当前生命周期选择最新失败工具，再与最新父调用错误比较。恢复前的旧错误不重用；失败后成功清理不会抹掉实际诊断。

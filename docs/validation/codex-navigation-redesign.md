# Paws 桌面导航改版与交互核对

日期：2026-11-12。原始开发基线：`1b1bc78e3100e3f1923ac855558040c5b786f0fe`；最终集成基线 `c638ceeba8fc0ad1e0b1fd52f4d1ec58ffe1076c`，包含输入框改进与项目工作区两栏更新。用户已授权按参考交互实施。本文记录本次导航范围的真实观察与实现，不代表 ChatGPT 全产品的业务功能验收。

## 目标和最终行为

将 Paws 桌面导航分成全局顶部栏、左侧主图标栏、会话侧栏和工作区。顶部栏独立占高 48px，在首页、新建、会话和项目路由提供返回、前进、侧栏与禅模式控制；支持右侧面板的宽屏页面在最右提供面板按钮。聊天标题释放旧悬浮控件占用的横向空间；窄文件分栏原有第二行仍保留。

会话侧栏顶部显示 Paws、清单图标、时间线铃铛和搜索图标；下面是新建会话。项目分组是主页默认视图，不另设项目文字标签；点击已选清单或时间线图标、或点击主页图标，返回项目分组。清单和时间线互斥，铃铛进入时间线，搜索打开既有命令面板。归档、应用会话及插件侧栏也保留新建和搜索入口。

主图标栏保留主页、动态中心、项目工作区、插件、归档、应用会话、账户和帮助；桌面栏不再重复显示新建或搜索。短窗口下主入口区可滚动，底部菜单保留位置。首页入口在悬停展开时也可固定会话栏。手机导航保留原有入口。

桌面首页的欢迎语居中，去掉粒子背景；新用户的右侧能力中心默认收起，已保存的面板开关偏好保持有效。右侧面板按钮位于顶栏最右，并保留现有会话文件、任务与子 Agent 详情动作；当前任务看板被子 Agent 覆盖时按钮按实际可见内容提示并执行。

## 验收 Case

| Case | 通过标准 | 已完成证据 |
| --- | --- | --- |
| NAV-1 | 顶部栏跨首页、新建、会话和项目路由可达，视觉与键盘顺序一致 | 真实完整 App 观察；组件回归 |
| NAV-2 | 主页项目分组、清单图标、铃铛时间线互斥切换；搜索与新建调用真实入口 | 实际点击、aria-pressed、命令面板与路由读回；归档和应用会话仍可使用顶部入口 |
| NAV-3 | 侧栏收起后空间回收；首页恢复可固定；项目禅模式恢复打开 | 实际状态读回、布局 Hook 回归 |
| NAV-4 | 250px 侧栏不溢出；900×500 时主栏滚动、账户和帮助可见 | 实际元素边界与滚动高度读回 |
| NAV-5 | 图标提示可由悬停和焦点获得，滚动/缩放关闭过期提示 | Portal 定位、提示文本与回归检查 |
| NAV-6 | 深色非默认主题使用当前主题普通与选中表面 | Gingham 深色实际界面与颜色读回 |
| NAV-7 | 浏览器 push/replace/pop、重复地址、回退前进正确；不把站外历史当作应用内入口 | 条目身份观察器回归；实际顶部返回/前进路径 |

全局返回/前进与项目内部的层级返回/前进分开处理。项目按钮使用包含当前层级的提示，避免与顶部浏览器历史混淆。Web 观察器为普通历史状态记录附加独立命名空间标记，保留路由字段；监听跟随浏览器文档生命周期，避免 Expo 前进时重挂载 React 根后丢失历史。非普通记录（例如 Date、Map、数组、空值和原始值）保持原语义；返回此类或未知条目时保守重置已知历史，应用内前进按钮可能暂时不可用。原生仍使用既有导航路径。

使用独立完整 App、隔离 PGlite 和合成账号/机器/会话。UI、路由与加密传输采用真实实现；执行器为测试替身，项目目录接口返回合成空列表，没有向外部模型发送验收消息。正式账号和生产数据未作为可写验收对象。

验收媒体是 11 个已验证状态的逐帧演示，不称为连续操作录像。MP4 为 1440×900、H.264/yuv420p、30fps、14.3 秒，完整解码通过并已通过 Happy 媒体卡片发送；未声称用户手机端已播放。项目页等待加载结束后采集，测试替身返回空项目目录，只证明导航和布局，不证明真实项目内容读取成功。真实浏览器关键帧已通过 Happy Skills 进度回传；凭据、生产会话正文和认证链接不进入本文或提交。

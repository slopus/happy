# 完整上下文接续：2026-11-27 扩展实现

本轮按用户追加要求补齐长历史、真实工具结果、历史原件与原生恢复；以下为当前实现契约。初版 #907/#910 的文字摘录方案及短事实验收仅作为后文历史记录，不能当作本轮完整接续通过的证据。本轮尚未发布或进行正式模型验收。

## 当前行为与数据路径

选择 Agent / 模型只暂存；普通发送箭头或 Enter 提交同聊天接手，独立“新建会话”保留。root 地址、标题和侧栏身份不变；实际发送、停止、审批与工具属于当前执行段。

1. 空闲源与完整 ownership 链校验后先 CAS 预占 root，再由执行机核对目标能力、连接与账号。App 不传任意原生 ID。可安全恢复时退休旧 native writer，仍建立一个新的 App 执行段，前驱链不回环。
2. 从原加密历史独立分页解密完整可携带条目，包含用户/助手正文、命令及完整输出、错误、退出码、计划和文件改动。读取不依赖 UI 已加载的窗口，也不移动当前阅读位置。
3. 完整归档和附件子密钥通过加密 RPC 分块校验 SHA-256 后，在授权执行机私有目录加密保存。服务端仍只中继密文。初始导入按 UTF-8 字节预算选择完整条目，默认最多 64,000 字节；删除旧的单条 6k、近期 50 条和总 24k 摘录路径。
4. 超预算条目由所有已接通 Happy MCP 的目标通过 `thread_read` 列表、搜索、itemId 与 textOffset 按需回查。`thread_attachment` 按清单下载原图、PDF 和媒体，返回可读图像或原文件路径，不信任旧本机路径或任意 URL。
5. 原生恢复仅按已证明进入 native 的连续历史前缀计算增量；没有附件实际消费证明时不跨越该文件条目。完整归档不因 native coverage 被删除。首次输入保留现有持久投递证据，未知结果不重放命令或另建替代 worker。
6. 独立 continuation 的继承前缀复用创建时的不可变加密归档；不追读父聊天后续消息，也不让父聊天之后的 `/clear` 改写该分支。

## 约束与诚实降级

- Claude、Codex、OpenCode / Antigravity 的真实结果 mapper 现在保存 `output` / `exitCode`。旧协议没有保留的结果尝试从本机 Claude / Codex 原生日志补取；原件已丢失或旧 provider 没有可读原始记录时明确标记历史缺口，不把 null 当成功，不为补结果重跑命令。
- 支持且具有可信连接、账号和退出证明的 Claude / 受管 Codex 原生会话可恢复。其余情况使用新原生线程加完整可回查历史；不根据模型名称推断能力。OpenClaw 当前没有此 MCP 通道，预检拒绝完整接续，独立普通新建仍保留。
- `/clear` / `/new` 在继续执行前持久化新边界，撤销旧归档权限；源/目标身份、边界或生命周期在上传和首条提交间变化时拒绝陈旧发送。显式旧 fork 缺少可验证截断 proof 时拒绝跨 Agent 完整切换，不猜父历史范围。
- 内部推理、进行中的工具、原 provider 审批与调用身份不作为可执行状态迁移。过去的已完成记录只作历史证据。
- 归档容量、原件下载容量等是明确失败的资源保护，不会静默裁掉源文本。当前归档资源上限 256 MiB；加密原件 64 MiB、流式媒体 500 MiB。模型/上游工具自身未保留的字节不能由本功能创造。
- 旧 schema clock 写回丢字段时，执行机的加密授权回执恢复同 epoch 的唯一归档；显式冲突仍失败关闭。取消须由 daemon 证明没有用户输入到达并确认 native writers 退出，才释放预占；取消的旧 requestId 不能被当普通发送重新执行。

## 正式模型验收与兼容恢复

在正式 Web、Mac mini、专属合成聊天中，源 Codex 记住三项随机事实。选择 Antigravity 只暂存、取消保留原草稿；实际普通箭头发送后同一 root URL 保持，Gemini 4 Neon 准确答出三项事实并完成。但旧 schema 客户端的消息时钟写回可能删掉新成员归属字段；root.active 仍指向目标，严格路由因字段遗失显示 unavailable，列表拆为两条。Retry 与完整刷新都未恢复。该轮只证明模型接续，不能作为同聊天通过。

修复要求：依权威 root.active、完整 predecessor 链、机器和目录确认缺失归属；冲突、歧义、循环或缺段仍拒绝；提交前重新核对保留位与目标，恢复不重发已交付消息。普通独立新建没有 root.active claim，不因 continuation 血缘被折叠。旧客户端仍运行旧代码时不能宣称服务端线性化防护；本次特定写入设备没有识别。

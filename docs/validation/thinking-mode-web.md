# Paws Web 思维模式

本次将认可的分类面板接入真实应用。基线为 `a256c122f62a1dcbfead2c671cbaf582f964ae95`；原型的合成回复没有进入产品代码。

## 功能与边界

- 设置 → 功能 → 界面：本浏览器 Local Storage 布尔开关，默认关闭，不随账号同步。
- 会话输入区只有一个方法入口。13 项包含原始 12 项思维框架和独立的 Teach Me，按五种用途分类，并区分直接分析、逐轮对话、比较后追问和持续学习。
- 选中方法按账号和会话存储，作用于此会话后续正常消息；取消或关闭时显式释放上一轮的方法指令，CLI slash commands 保持原样。
- 模板和可见消息分开。正常提交继续使用原有队列、附件、批注、文件及会话引用处理；图片无正文时显示附件文案，避免暴露隐藏提示词。
- 回复末尾“继续追问”默认折叠。画出来（Show Me）、举个例子、继续讲解和两个建议问题直接进入原发送队列；携带所点击回复的稳定 ID 和完整正文，独立于输入草稿和会话方法。
- 本次功能只在 Web 展示。Native 使用空 UI 和原样发送适配，无原生依赖、权限或 runtime 变化。共享接入和翻译仍由现有 CI 保守判定 OTA。

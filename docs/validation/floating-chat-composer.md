# Web 聊天输入框悬浮与标签栏精简

## 目标与实现

以 `1f0d24c4937f3efc992b35783f14a90e0cb49718` 为基线，按用户提供的 Paws / T3 Code 截图调整已有会话页。
消息视口延伸至底部，输入区悬浮覆盖；只有消息末尾按输入区实际高度留白。
保留现有输入框、字体、主题表面、状态、附件与发送操作，不另加背景层。
Web 输入框上方的标签条（含空标签的 `+`）不再渲染；标题 `#` 和侧栏组织入口保留。
原生布局、键盘避让和标签入口保持原行为。

`AgentContentView.web.tsx` 测量整个输入区（状态、附件、队列及恢复提示），将高度限定在本会话的 context 中。
`ConversationTranscript` 在滚动内容末尾留空间，并抬高回到底部、历史提示及目录按钮；Web 锚点轨道也避开输入区。
锚点跳转按未被输入区覆盖的高度居中，超高提示从可见顶部开始；挂载等待中的定位读取最新输入高度。
透明边缘允许消息接收指针事件，输入框本身保持可编辑。未添加业务轮询。

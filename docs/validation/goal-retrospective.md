# Goal First 任务复盘整理

2026-11-20；实现分支基于 408a6a032560bf25fd935c7b53f6ed7e51901e66。

## 行为

- 项目/子目标顶部提供复盘入口，原任务进度图标可点击修改。复盘可选择全部或部分任务，先呈现具体待判断项和实际未完成工作；自动整理与依据按需展开。
- YAML status 仍是唯一当前进度；paws:review 记录摘要、依据、用户问题/答复、工作缺口、版本认可与状态变更事件。手动改状态、AI 修正状态、交付认可分别表达。
- 状态保存使用现有加密文件 RPC 的 expectedHash 冲突保护；撤回只改对应状态和事件，不还原整篇文件。错误、账号切换和旧响应不应覆盖新记录。
- 历史认可仅复用有来源且匹配实际本地最终产物 revision 的记录；版本变化失效。网络 URL 的哈希不是内容版本，不自动携带历史内容认可；现有明确链接审阅仍只认可链接。
- 创建复盘会话时准备限于所选任务的草稿，用户发送后才运行。复盘整理只记录已有工作和缺口，不补做实现、生成、测试或发布。
- 日常维护规则进入任务交接提示及 Codex/Claude 会话提示；事件触发，不新增轮询。

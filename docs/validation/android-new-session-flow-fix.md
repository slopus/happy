# Android 新建会话修复与验收

本次基线为 `375cefbead32b8e494c37b86a5a1f8092c7cf98c`。用户在 2026-11-28 认可前轮诊断流程并明确授权修复；原始故障与截图边界见 [诊断报告](android-new-session-audit-20261127.md)。

## 实现范围

- 原生工具栏保留添加、权限和发送动作的自然宽度，让模型标签使用剩余空间，不以缩小字号修补裁切。
- 型号、力度和权限原生浮层复用安全区与键盘避让底部面板，不再沿用键盘关闭前测量的触发器坐标。Web 保留原浮层定位。
- 关键可操作型号/权限文字消费当前主题的正文色；保留风险语义和辅助说明。原生首页可滚动，以容纳短屏与键盘组合。
- 新建页按当前机器与工作目录直接请求 Antigravity ACP 能力，首次使用无需先有历史会话。选择与刷新动作触发读取，同目录在途请求复用，原生握手有单次期限并清理进程，不加入轮询。
- 已有机器连接后，在真实 RPC 注册完成后补发能力声明；沿现有加密版本比较更新合并机器资料，不覆盖 App 同时修改的名称或目录，重连不重复写入。
- 目录加载/失败/不可用状态在既有临时选择面板呈现。显式选择在目录未知或失败时保留；确认已移除的型号/力度阻止错误配置发送，并允许重新选择。首消息在能力元数据尚未加载时也保留用户明确选择的力度。
- 保留既有 Agent 图标循环切换方式，没有增加输入区常驻入口或功能条，没有变更原生模块、权限、包名或 runtime。

| 原生组件 | 现有 `build.paws.dev` 开发壳加载本次真实输入框与选择器；模型目录和发送回调使用有标识的测试数据，不能替代完整 App 或真实模型 |

| 发行与用户手机 | PR/CI/OTA 制品、执行端激活与用户当前手机分别记录，不互相替代 |

## 已执行证据

- Task 1 先观察到工具栏几何、原生锚点阻塞、权限定位、目录恢复及首页滚动的回归失败，再修复。最终四个定向文件 88 项通过，包含 320/360/390/430dp Yoga 检查与关闭/重开行为。
- 初步全量快照为 6392 项通过、2 项仍在实施的 Antigravity 新回归失败；该历史结果不作为最终绿色结论。独立评审补修后完整 App 为 662 文件 / 6411 项通过，App 完整类型检查通过。
- 实际 ACP 能力握手返回 11 个模型，耗时约 6.18 秒（含清理）。当时当前型号为 Gemini 4 Neon、力度 high；Neon 支持 low/medium/high/xhigh。不同型号范围分别以真实返回为准，不硬编码或按另一型号推断。
- 原生第一轮 411dp 的 confirm 标签可见宽度从基线 17px 恢复到 128px；320/360/390/430dp 和 320dp / fontScale 1.3 的实际组件几何与本地发送回调通过。真实拼音提交“你好”、型号搜索和选择、力度切换、权限选择、返回及草稿保持已实测，覆盖 Caramel 浅色和 Gingham 深色。无力度时直接进入型号列表，返回后仍可使用已有 Agent 轮换表面。
- IME 收起后的稳定帧确认面板距 2298px 窗口底部约 65px，符合安全区；同轮输入法状态为 false、窗口为完整高度。早期 IME 过渡帧不作为最终定位证据。19.166667 秒连续原生录像已完整解码、核对哈希并通过 Happy 交付，未将未成功的 Medium 点击计作力度变化。
- 独立代码评审发现的“同型号力度失效无法重选恢复”和“切入 Antigravity 时历史目录的型号被固化”均先失败再修复；新增 4 项回归通过，相关 App 定向检查 126 项、ACP 148 项、Wire 5 项通过。无剩余 Critical / Important 评审问题。
- 配套内置候选保留活动运行包非目标源码，三方合入本次 CLI / Wire 差异，682 个其他源码文件保持。构建、类型检查和 6 个 ACP 文件 / 143 项检查通过；激活与实际加密 RPC 另行记录。
- CLI 完整检查首轮 53 项失败来自继承当前会话的账号/共享连接环境和未解包的测试工具。按项目脚本解包，并只在测试子进程清理对应环境后，4 个失败文件 / 112 项全部通过；没有修改真实账号或全局配置。完整重验结果沿本轮发行回执维护。
- 已有机器能力声明先观察到缺失写入的失败，再补修；API 与目录两个文件 22 项通过，包括加密版本冲突、并发资料保留、重连及未注册处理器的分支。

# 全局会话入口数量提醒

## 行为

- 左上蓝色数字显示执行中会话数；右上金黄色数字显示需处理与待查看的总数。
- 角标采用白字、略向内收尖的胶囊。0分别隐藏，超过99显示99+，悬浮和可访问说明保留完整数量。
- 浮窗OFF时仍可打开。开启后ON位于右下角，数字保留；打开列表不标记会话已读。
- 入口优先打开需处理，其次待查看，再沿用原默认分类。归档、删除和断线未知继续沿用已有筛选。
- 颜色取自当前主题的activityBadge语义角色，蓝色与金黄色派生到对白字至少4.5:1。未新增计时器或轮询。

## 验证

- 4个定向文件共77项测试通过：ProjectSessionMonitor、sessionActivity、SidebarView、themePacks。完整typecheck与git diff --check通过。
- 颜色回归覆盖全部主题；组件覆盖Gingham深色与Terminal浅色。独立代码review通过。
- 完整隔离App通过真实本地relay与合成会话事件验证：需处理1＋待查看1显示金黄2，执行中1显示蓝1；OFF可点击，ON与待查看卡片及数字共存。
- 浏览器实测单数字宽22、高17，白字；双99+不可见布局副本各宽28.09375px、间距1.8125px，未重叠或裁切。该布局测量不等于200条真实会话端到端验收。
- 最终源码两张绑定截图均校验、上报成功，衍生图已发送给用户；用户认可最终样式并授权上线。

# 项目会话目录：按需完整历史

## 问题与结果

用户反馈展开后持续转圈。正式网页实测旧路径为60次目录RPC及1次分组RPC，约20.27MB WebSocket响应，75.384秒才结束；期间没有历史行。源码还会把普通项目文件revision当成整账号目录刷新。

普通展开、恢复记忆和普通文件revision现在只展示已同步会话，不启动完整目录读取。完整历史由“加载完整历史”或刷新动作触发。未知总量保留“—”，未读取完整历史时显示“当前显示已同步会话”，空分组显示“暂无已同步会话”。

主动读取保留原有完整快照、指纹、Task权威归属、分页、180秒截止及取消隔离；增加真实分页进度和取消入口。目录数据读完但仍在验证/分组时不展示100%完成。首次完整历史的底层全账号遍历仍可能慢，本次没有新增按scope后端查询。

## 设计与范围

PC项目页右侧既有目录样式与33px紧凑行保持，继续复用WorkspaceTreeRow/WorkspaceButton及当前主题text/textSecondary/textLink。已同步、未加载、读取进度、整理、取消、失败、离线均有文字；只在用户请求读取期间显示spinner，不因目录展开或文件更新改变布局为持续等待。

不修改移动原生实现、CLI、服务端、加密协议或业务数据；无新增存储、定时刷新、服务或部署目标。

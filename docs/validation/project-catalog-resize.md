# 项目任务区拖动调宽

用户截图箭头对应任务目录与中间对话的边界。直接修改原项目工作区，替换原有 10px 间距；不新增页面或改变主题。

## 行为

- 桌面 Web 在该边界悬停时显示左右调宽光标及当前主题强调线；拖动实时调整任务区及中间对话/文件区比例。
- 全局和任务对话共用该宽度；同一项目页面内切换任务保留偏好，刷新不持久化。
- 任务区最小 280px；中间区保留 360px，右侧详情宽度不变。窗口缩小时自动限制可见宽度。
- 支持左右方向键、Home/End、双击恢复自动比例；最大化文件或无中间区域时隐藏分隔边。
- 松手、取消、失去捕获、窗口失焦和卸载后清理拖动状态及全局光标/选区样式。

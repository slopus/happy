# 项目会话保留原任务卡片

基线：c638ceeba8fc0ad1e0b1fd52f4d1ec58ffe1076c。用户在正式页面标注：希望外侧原任务卡片仍然可见，打开对话只收窄卡片区域。

## 交互契约

- 桌面默认保留原卡片与详情；打开会话后成为“原卡片｜会话｜详情”。复用原 TaskCards，不替换为文字导航；搜索、筛选、选中态、卡片会话入口仍可用。
- 会话/文档共用中间区域，文件树按需在右侧展示。阅读文件时为“原卡片｜正文｜文件树”，切回会话仍可见卡片；不堆叠成四栏。
- 明确放大文件时暂时隐藏卡片；关闭放大文件恢复卡片与会话，并清理旧放大状态，再次打开不意外隐藏卡片。
- 宽屏卡片区可容纳两列原卡片，笔记本宽度收为一列。分配保留中心至少360px。卡片区可独立滚动，各会话保留未发送草稿；移动端继续原有分屏路径。

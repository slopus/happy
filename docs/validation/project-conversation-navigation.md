## 行为与数据

PC Web的全局目标及任务右栏新增会话页签。项目总量与每组数量来自daemon授权聚合历史；每组分页，不把已加载25条称完整数量。项目全局、子项目全局与任务历史统一列出，切换保留taskId/feature路径；根项目直属任务仍明确加载其board。新建按钮创建目标范围的真实空会话，不发送任务。详情及文件页签沿用原工作区，SessionView继续拥有草稿与聚焦后的未读清除。

状态来自现有buildSessionActivity/resolveSessionState，含需回复/授权、失败、待查看、执行中、离线未知及已完成。无可用live header的冷历史显示历史会话，不从executed推断完成；提醒只覆盖已同步状态。迁移后的稳定任务按身份归属，旧路径不覆盖权威分组。

新RPC goalProjectConversationCatalog在当前项目catalog内授权：daemon有限读取完整账号目录，固定为五分钟有效的不可变读取结果，按256KiB以内分页投影加密metadata、包装后的记录密钥及版本；agentState与消息尾部不传给Web。已登录Web仅在本地解密metadata，完整校验数量和全目录id/metadataVersion指纹后，向所选机器传紧凑归属候选及快照token，不导出密钥、凭据、正文或其他机器明文。goalProjectConversations校验同一冻结目录及候选版本后，返回完整总量及有界分页；不再二读变化中的目录，排除归档和身份冲突。总量表示本次完整分页观察结果，不承诺数据库单时刻快照；实时状态仍沿已有会话同步。快照惰性过期、限制数量及总内存；Web只缓存两份已完成目录供历史分页复用，刷新获取新快照。候选请求限制512KiB，数据不完整时显式报错。事件revision与用户刷新触发单次读，无定时业务轮询。原生平台使用空Provider，保留原界面；共享运行文件仍由现有CI判定OTA范围，不主观跳过。

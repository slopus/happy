# Codex multi-account usage attribution

Ego browser acceptance evidence captured from an isolated local environment at
1440×900. The seeded values are synthetic and exist only for this regression.

- `case-before.png`: `origin/main` baseline without account selection.
- `case-work-after.png`: work account, 77% remaining and 1.80 亿 tokens / 6 sessions.
- `case-personal-after.png`: personal account, 39% remaining and 0.70 亿 tokens / 3 sessions.
- `case-unattributed-after.png`: unattributed activity, 0.30 亿 tokens / 1 session.
- `case-all-after.png`: aggregate activity, 2.80 亿 tokens / 10 sessions.
- `codex-usage-multi-account-e2e.mp4`: the full account-switching flow.

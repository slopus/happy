# Goal 产物独立阅读窗口

用户指出核心文档覆盖聊天正文后，明确要求改为独立文档阅读窗口。本轮沿用已认可的 existing-ui-design 方案和现有主题，没有调整看板的信息结构。

## 行为

从任务详情打开原件时，使用 RN Modal portal 呈现居中阅读窗口：最大宽1120、高800，四周至少24留白，带主题遮罩和独立滚动。任务详情和对话保留在后方，关闭、Esc或遮罩返回同一文件入口，未发送草稿保留。紧凑抽屉不再因打开文件而关闭，其键盘处理会让出上层portal窗口。

复用原文、Markdown/源码切换和附件通道。图片预览在同一个Modal中使用现有SessionImageViewer，不额外呈现一个原生Modal，也不把当前产物混入会话图片历史。关闭图片恢复缩略图焦点，阅读器持续挂载。Escape按keydown时的归属处理，避免图片keydown关闭后，同次keyup误关底层文档。

# agy Skills 与会话授权验证

## 结果与范围

修复 ACP 工具参数丢失、技能读取漏识别和授权范围失真。官方 agy 1.5.13 的真实协议探针只返回 allow_once / reject_once，不能把 Claude 的 allowedTools 当作持续授权。Paws 的“完全访问”通过显式会话策略提供，保留风险确认，并等待执行端确认后更新页面。

本地实现及独立代码评审已通过；正式发布、执行端激活与真实页面工具回合尚待独立验收。此前仅验证文字收发的结论不覆盖工具、Skills 或权限。原业务会话不重放、不停止。

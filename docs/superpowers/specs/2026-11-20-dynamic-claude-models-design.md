# Paws 按连接动态获取 Claude 模型目录

## 目标

Paws 不再为 Claude 模型维护固定版本号。用户在 MagPie 更新配置或执行端更新模型目录后，下一次打开模型菜单即可获取当前目录，无需再次发布 Paws。协议与界面能力变化仍可能需要升级。

## 已验证基础

当前 Paws 的 Claude 回退选项把 opus/sonnet/haiku 别名写成固定版本号。原生 Claude 的 initialize 控制响应实际提供 models，包括 value、resolvedModel、displayName 及 supportedEffortLevels；本机只读探针已返回 Opus 5.5 和 MagPie 的其他可选模型。探针未提交用户提示词或发起模型推理。Codex 已有独立连接目录及按需刷新，继续复用。

## 方案与取舍

采用执行端原生目录，经 Paws 现有加密 RPC/会话元数据传递。新建页可在没有历史 Claude 会话时从目标机器读取，运行会话在自身连接范围更新目录。直接从前端请求 MagPie 会失去远端设备、有效 CLI 配置和凭据边界；只改固定型号仍需每次发布，均不采用。

## 行为

- 打开模型菜单、切换目标机器/执行器和显式刷新时执行单次查询；合并并发请求，不增加后台定时轮询。
- 使用原生目录的模型标识、名称与推理档位；新型号无需前端新增枚举。别名映射到同一型号时保留可辨认的入口，不凭名称合并不同身份。
- 新建页与会话菜单均使用目标执行器/连接的目录，切换机器时拒绝迟到响应。官方账号与 MagPie 目录保持隔离。
- 旧 CLI、不支持目录、离线或读取失败时明确处理；无可信目录时仅显示 CLI 自动/无版本号别名，不伪造型号。失败不把旧快照标成刚刷新成功，也不自动更换用户所选模型。
- 查询过程不提交提示词、不切默认账号/模型、不重启在跑会话；使用有界超时并释放探针进程。
- 目录可见与实际推理可用分别验证和报告。

## 实施与验收

1. 执行端提取原生模型目录，注册有界只读机器查询并更新 Claude 会话元数据；保留受限应用连接边界。
2. 新建页与会话模型菜单接入按需刷新，移除 Claude 固定版本标签，使用动态推理档位。
3. 回归覆盖目录变化、默认/别名、失败、旧执行端、切机器竞态、账号隔离及无提示词探针；运行适用类型检查和构建。
4. 按项目既有 PR/CI 流程交付 Web/OTA，执行端激活另行核验；不新增 npm/APK 发布。截图遵循项目的独立确认规则。

用户于 2026-11-20 明确选择“按此方案实现动态获取”，本设计已批准。实施与发布结果另见验收记录。

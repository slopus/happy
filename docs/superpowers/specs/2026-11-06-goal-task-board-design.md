# 会话 Goal First 任务看板

用户已确认现有 Paws 界面中的右上角可折叠看板，并于 2026-11-06 明确授权直接开发、接入真实数据、测试重点功能及性能。本任务不包含 Tauri、blend 或正式发布/合并。

## 用户路径

右上角入口显示任务完成数；展开后选择/关联当前会话的 Goal First feature，后续记住关联。显示真实任务状态，支持当前批次/全部、搜索与筛选；会话本轮已完成不等于目标完成。

任务详情优先回答目标、解决的问题、当前阶段及实际阶段交付。每个产物有类型、名称、用途和真实入口。计划交付、相关参考、实际产出及验收状态分别表达，不增加摘要文件、不把合同或历史成品算作本轮产物。状态、下一步、依赖及过程来源可展开查看。

文件卡直接打开完整原件：Markdown 排版预览/源码，其他文本代码阅读；图片复用图片查看器，音视频复用播放器，PDF复用系统打开/分享或下载。实际文件缺失、机器离线、类型不支持和超限须明确反馈。不得公开私人文档或另开文件隧道。

任务可继续已有会话或在同一机器开启独立会话。传入目标、问题、原任务说明入口、已有关联产物和下一步；创建不自动修改任务执行状态。继承原会话agent和Codex账号约束，防重复点击，保留主对话草稿和返回入口。

## 数据与性能

只读解析已安装 Goal First 的项目/feature/task记录，优先实际导航中的G编号映射，跨feature任务去重，不硬编码示例20项或用户路径。首次无法唯一定位时让用户从候选feature中关联，绑定和快照保存在现有加密会话metadata。

文件变更使用fs.watch事件更新加密metadata；无定时任务/状态/文件查询。关闭看板不重新加载正文；未打开文件不读取其内容、不上传媒体。文本读取有大小上限与缓存，媒体通过现有附件链路按用户动作准备。现有文件面板的5秒整文件轮询移除，保留用户单次刷新。所有路径校验真实路径和符号链接，跨出授权Goal资料根的链接不得自动读取。

## 验收Case

C1 当前会话绑定目标、真实计数、开合/搜索/筛选及缓存恢复。
C2 目标、问题、阶段、真实产物与计划/历史区分；未知字段不伪造。
C3 Markdown/代码完整阅读；中文/空格路径；缺失/超限/离线反馈。
C4 图片、音视频、PDF的现有展示/打开链路，按需加载。
C5 继续/开启任务会话、继承执行配置、重复点击、返回与草稿保持。
C6 事件更新，无业务轮询；看板开合与文件阅读性能检查。
C7 桌面宽/窄布局、键盘、主题（含非默认深色）与焦点恢复。

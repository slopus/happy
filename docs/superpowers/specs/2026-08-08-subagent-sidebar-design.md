# 子 Agent 侧边栏详情设计

日期：2026-08-08
状态：已批准，待规格审阅

## 背景

会话中的「子 Agent」活动行目前只显示路径和状态。Codex CLI 已把子 Agent 的可见消息、工具调用和文件修改归属到稳定的 `subagent` ID，并嵌套在启动它的 `Agent` 工具消息下；但用户没有从活动行进入这些内容的入口。

## 目标

1. 点击任意子 Agent 活动行后，在当前会话的右侧面板查看该 Agent 的已捕获记录。
2. 桌面端展开既有右侧工作区面板；手机/窄屏端打开既有右滑抽屉。
3. 在侧边栏按时间呈现 Agent 的可见文本、工具调用、文件修改和嵌套子 Agent 内容。
4. 保留原有能力面板和文件面板；关闭或返回后恢复此前的面板。
5. 内容缺失时明确告知，绝不以状态或本机原始日志伪造详细记录。

## 非目标

- 不读取、上传或展示 `~/.codex/sessions` 中的原始 rollout 文件。
- 不展示隐藏 reasoning、认证信息、环境变量或其他敏感内容。
- 不改变 Codex CLI 的子 Agent 映射协议、会话持久化格式或 API Key 配置。
- 不新增独立路由、第三个常驻工作区列或常驻的右栏标签。
- 不改变现有 Skill、工具活动或普通 Agent 工具卡片的展示规则。

## 方案选择

采用「上下文替换现有右侧面板」：活动行点击后，当前右侧面板显示子 Agent 检查器；检查器顶部的返回按钮清除选择，回到之前的能力或文件面板。

未采用：

- **原地展开**：长子 Agent 记录会淹没主对话，并使嵌套层级难以浏览。
- **新增常驻标签**：没有选中子 Agent 时占用导航和空间，且与一次性查看行为不匹配。
- **新路由或模态页**：打断会话上下文，也不能复用已有的桌面右栏和移动端抽屉无障碍处理。

## 交互规格

### 活动行

- 子 Agent 行改为可访问的 `Pressable`，提供明确的按钮角色、标签和展开状态。
- 点击后传递 `subagent` ID、当前标题与状态；不在活动行存储或复制完整消息树。
- Skill 行保持不可点击，现有缩进、状态图标和状态文本不变。

### 检查器

- 顶部显示返回、`子 Agent` 标签、路径/标题和最近状态。
- 正文首先显示该 Agent 工具输入中已同步的任务提示，随后显示可见进度、工具操作、文件修改与最终回复；任务提示使用独立「任务」区块，不伪装成用户消息。
- 正文以时间顺序渲染该 Agent 的嵌套消息树，复用现有 `MessageView`、工具卡和文件导航，避免制作第二套内容渲染器。
- 若该 ID 在完整会话消息树中找不到拥有它的 `Agent` 工具消息，显示空状态「未捕获详细记录」和当前状态；返回仍可用。
- 嵌套子 Agent 继续显示在其父 Agent 工具内容中；再次点击活动行时在同一检查器切换目标。

### 响应式行为

- 在支持持久右栏的桌面工作区，选择子 Agent 自动展开右栏并显示检查器；文件面板选择会暂存，返回时恢复。
- 在手机和窄屏中，选择子 Agent 自动打开已有 `RightSwipePanelHost` 抽屉；保留返回键、焦点隔离、手势和关闭行为，但不显示右侧常驻或突出的 edge handle。
- 在没有可用会话或右栏不可用时，活动行不显示为可操作入口。

## 组件与数据流

1. 在 `conversationActivity` 附近新增纯函数，从整个会话消息树按 `sessionSubagent` 找到目标 `Agent` 工具及其 children，并按时间输出可渲染的 transcript。
2. 新建会话范围的 `SubagentInspectorContext`，状态仅包含选择的 `subagent` ID、标题与状态，以及 `open`/`close` 操作。
3. `ConversationActivityStrip` 通过 Context 打开检查器；不向 `ToolGroupView`、`TaskView` 或 `ChatList` 层层传递回调。
4. `SessionView` 负责在选择时展开桌面右栏或右滑抽屉，并把检查器作为 `SessionRightPanelContent` 的临时内容。
5. `SubagentInspectorPanel` 用会话完整消息数据重新解析所选 transcript，并以 `MessageView` 渲染。所有数据都来自 Happy 已同步的会话消息。

## 错误与边界

- 历史 CLI 映射缺失、已清理的消息或不完整同步时显示空状态，不尝试访问执行机文件系统。
- 未知状态按现有状态组件退化显示；运行中的 Agent 随消息同步自动更新。
- 切换会话或卸载 `SessionView` 时清除选择，避免将一个会话的 Agent 详情带到另一个会话。
- 所有子 Agent 输入、可见消息和工具输出沿用现有脱敏/渲染边界；检查器不引入新的原始 JSON 调试入口。

## 测试与验收

### 单元测试

- transcript 查找函数：直接子 Agent、嵌套子 Agent、时间排序、找不到目标与同名/不同 ID 场景。
- 检查器 Context：选择、替换选择、关闭与会话切换清理。

### 组件测试

- 活动行具备按钮语义，点击调用打开操作；Skill 行不变。
- 检查器渲染标题、状态和来自目标 Agent 的消息，且空状态不包含伪造内容。
- 返回按钮恢复默认右栏内容。

### 集成与视觉验收

- 桌面：点击已完成子 Agent 行，右栏自动展开并展示记录；返回后恢复原选项卡。
- 窄屏：点击活动行打开右滑抽屉；关闭后主聊天仍可操作。
- 嵌套子 Agent：选中子 Agent 的内容不泄漏到根会话或同级 Agent。
- 执行相关 Web E2E、App typecheck 和 Web export；为可见用例生成 before/after 证据并发布公开 HTML 预览。

## 验收清单

- [ ] 子 Agent 行可点击且具备正确无障碍语义。
- [ ] 桌面与窄屏均在既有右侧面板体系中打开详情。
- [ ] 详情仅展示已同步的可见内容，不展示 reasoning 或本机原始日志。
- [ ] 空记录状态清晰、可返回且不影响主会话。
- [ ] 返回后恢复此前能力/文件面板状态。
- [ ] 相关单元、组件、E2E、类型检查与 Web export 有新鲜通过证据。

# 批量批注独立评审

评审日期：2026-10-19。评审者独立于实现者；检查完整业务 diff、新增批注模块、测试夹具及现有验收证据，没有操作浏览器或重新执行 E2E。

## 代码功能验收：pass

选区绑定保留渲染文本偏移及原文校验，重复原文按消息和位置区分；汇总支持评论回填、保存同一 ID、取消和删除。草稿复用账号存储命名空间并按会话隔离；提交沿用现有暂存、加密及发送通道，支持仅批注或混合普通输入，清理按 ID＋revision 快照保留异步新增和修改。

发现并关闭一项 P2：消息已被暂存队列接受后，如果清理批注的持久化写入失败，原实现会误报发送失败并保留可再次提交的内容。修复后分别处理提交失败与清理失败：已接受快照在当前内存中退休，匹配的普通输入及附件正常清理，另提示“已提交”、刷新可能恢复旧批注及避免重复提交。普通添加、编辑、删除仍要求持久化成功才发布状态；新增单测覆盖失败通知、异步新草稿保留及刷新边界。独立复核修复通过，未发现其他阻断本次需求的问题。

## 桌面静态交互评审：pass

主模式为 pc-web-interaction-reviewer 的截图评审。独立观察 1440×900 桌面状态帧：单条与多条汇总、铅笔回填、刷新恢复、失败保留、批量提问正文、深色 hover 及最终汇总。列表、编号、原文与评论层级明确，编辑器操作可见，未见本次新增遮挡、横向溢出或与现有主题明显不一致。左右区域承载原有会话导航和能力卡；不从静态画面推断其收起及恢复行为。

补充复核最终 ANN-11 异常提示帧：对话框完整处于桌面视口内，标题“已提交”、清理失败说明、刷新风险与避免重复提交的提示均可读，“确定”按钮完整可见；与背景有明确层级。该新帧对应修复后的实现；原有七张状态帧早于异常文案修复，不用于证明新增异常提示。

## 建议基准

以400px宽、单行意见约75px高为首个可验证目标：外层padding0、圆角约14；内容padding10px 16px；头部24px、间隔6px、意见行高23px，加2px边框约75px。元信息和意见均可从14px起步，用灰度及字重分层。缩略约28×22、图标16px，无需整体放大。

去掉内部弧形分隔线和条目卡片感，整张浮卡承担柔和投影与约1.02倍hover；直接消费适合浮层的语义阴影值，不再重复衰减已有alpha。多条状态另做分组验收，不把单条高度当作整个多条容器的固定高度。

下一轮只用单条、浅色、相同意见、相同卡片宽度做并排对照，先验比例、padding和投影，再验缩略内容及hover。当前结论来自独立评审，本轮未修改实现。

# 계획

상태: 로컬 구현·검증 완료 / 릴리스 대기 (2026-10-02)

## 아키텍처 영향
Core: 기존 daemon의 자격증명 custody와 인증 원자성을 소유하는 merge 내부 변경이다. 새 의존성·공개 API·스키마·권한 변경은 없다. Desktop 온보딩은 기존 deploy API로 이 동작을 소비한다.

1. 런타임 경계에서 실패 테스트: 무효→유효, 유효 보존, 네트워크/한도/공용 무효 보존, active 갱신.
2. 기존 실제 요청 검증과 repair 적용 경로를 재사용하고 추가 계정 merge를 유지한다.
3. 관련 테스트·타입·빌드, 문서 동기화.

릴리스·tag push·배포는 미승인이다. 기존 공식 pin은 유지하고, 검증된 변경을 릴리스할 때 별도 승인받는다. 되돌리기는 merge 중복 갱신 코드 제거 및 이전 공식 CLI 사용이다.

## 검증 결과

관련 3파일 366건, TypeScript·번들 build·diff check 통과. 시간 예산은 각 단계 60초로 제한하고 기존 verifier 기본값은 보존한다. 사용자 후속 지시로 Desktop 연결은 다음 작업까지 보류한다.

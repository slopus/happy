# MOTION-VIEWER-01

Honor motion photos now remain ordinary still images in the chat stream. Opening
the image uses the fullscreen image viewer, where a dedicated motion-photo
control starts or stops the embedded video. The original-file download remains
available beside the chat image.

- `motion-viewer-01-before.png`: previous chat-level play overlay.
- `motion-viewer-01-after.png`: chat stream after, with a clean still image.
- `motion-viewer-01-viewer-after.png`: fullscreen viewer while motion is playing.
- `motion-viewer-01-mobile-after.png`: 390x844 Mobile Web chat state.
